# Worldcore Horse Portfolio

正式域名：`worldcore.work`

这是赛马版作品集：

- 16 帧马匹动作
- 未使用的旧素材已排除
- 0–8 背景顺序
- 每张背景单独的道路位置
- 三个 echo 马蹄印项目链接
- 2D 滚动叙事，不使用 3D
- 不使用小草
- 不使用红色

## 本地预览

```bash
python3 -m http.server 4181
```

访问：`http://localhost:4181`

## 上线

推荐部署到 Vercel 或 Cloudflare Pages，然后在阿里云 DNS 绑定 `worldcore.work`。

## 需要替换

- 三个 `echo ↗` 的真实项目链接
- 联系方式
- 正式 favicon 和其它页面文案
